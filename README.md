# resume_builder

## Purpose
항상 단조롭고, 복잡한 국문 이력서가 불편하고 보기 힘들어서 개발한 이력서 양식입니다.  
UI는 미니멀하게 가져가면서도, 자신이 강조하고 싶은 내용을 변경하고, 추가할 수 있게 만들었습니다.  
 편하게 쓰시고 후기 남겨주시면 감사하겠습니다!!
## How to use

1. `resume_template.html`을 Chrome, Edge, Firefox 또는 Safari로 엽니다.
2. 이력서의 글자를 클릭해 내용을 직접 수정합니다.
3. 항목에 마우스를 올려 추가, 이동, 삭제 기능을 사용합니다.
4. 사진이나 아이콘을 클릭해 원하는 이미지로 변경합니다.
5. `HTML 사본 저장`으로 계속 편집할 파일을 내려받거나, `인쇄 PDF 저장`으로 제출용 PDF를 만듭니다.

작성 내용은 현재 브라우저에도 자동으로 임시 저장됩니다. 브라우저 데이터를 지우거나 다른 기기로 옮길 때를 대비해 HTML 사본을 별도로 보관하세요.

기본 아이콘은 `icon/` 폴더의 오픈소스 SVG 파일을 사용합니다. 이력서를 다른 위치로 옮기거나 전달할 때 `resume_template.html`과 `icon/` 폴더의 상대 위치를 유지하세요. 아이콘의 출처와 라이선스는 `icon/README.md`와 `icon/LICENSE`에서 확인할 수 있습니다.
