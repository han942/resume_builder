## Purpose
항상 단조롭고, 복잡한 국문 이력서가 불편하고 보기 힘들어서 개발한 이력서 양식입니다.  
UI는 미니멀하게 가져가면서도, 자신이 강조하고 싶은 내용을 변경하고, 추가할 수 있게 만들었습니다.  
 편하게 쓰시고 후기 남겨주시면 감사하겠습니다!!
## How to use

1. `resume_template.html`(기본형) 또는 `resume_template_compact.html`(간격을 줄인 Compact형)을 Chrome, Edge, Firefox 또는 Safari로 엽니다.
2. 이력서의 글자를 클릭해 내용을 직접 수정합니다.
3. 항목에 마우스를 올려 추가, 이동, 삭제 기능을 사용합니다.
4. 사진이나 아이콘을 클릭해 원하는 이미지로 변경합니다.
5. `인쇄 PDF 저장`으로 제출용 PDF를 만듭니다.

작성 내용은 현재 브라우저에 자동으로 임시 저장됩니다. 브라우저 데이터를 지우면 작성 내용도 사라질 수 있으므로 주의하세요.

Compact형은 기본형의 편집 기능과 본문 글자 크기를 유지하면서 섹션·항목 간격, 줄간격, 사진 크기와 A4 인쇄 여백을 줄인 버전입니다. 두 버전의 작성 내용은 각각 별도로 저장되며 자동으로 옮겨지지 않습니다.

Compact형의 프로젝트와 경력 내 세부 경험은 제목 옆에 역할을 작은 글씨로, 같은 줄 오른쪽에 기간을 표시합니다. 각 필드는 클릭해 따로 수정할 수 있으며, 좁은 화면에서는 줄바꿈됩니다. 이전 Compact형의 저장 내용도 이 배치로 자동 적용됩니다.

학력은 학교명 옆에 전공·학점을, 오른쪽에 재학 기간을 표시합니다. 경력은 회사명 오른쪽에 재직 기간을 표시하고, 직무·직책과 고용 형태는 그 아래 줄에 유지합니다. 스킬은 태그 대신 자유롭게 줄바꿈하며 작성하는 일반 텍스트이며, 이전에 저장한 스킬도 텍스트로 이어집니다.

상단 슬라이더를 드래그하거나 슬라이더 위에서 마우스 휠을 움직여 섹션 간격(0~32px), 프로젝트·항목 간격(0~24px), 본문 줄간격(1.20~1.80)을 조절할 수 있습니다. 슬라이더 옆 숫자를 클릭해 직접 입력해도 즉시 적용되며, 줄간격은 1.35처럼 소수 둘째 자리까지 지정할 수 있습니다. 설정은 브라우저에 자동 저장되고 PDF에도 적용됩니다. `간격 기본값`은 작성 내용을 유지하며 간격만 되돌립니다.

Compact형에서는 편집 버튼을 기본적으로 숨겨 버튼 줄이 차지하던 빈 공간을 없앴습니다. 항목 추가·이동·삭제 시 상단의 `편집 버튼 표시`를 켜세요. 본문은 버튼 표시 여부와 관계없이 직접 수정할 수 있습니다.

학력·경력·프로젝트·수상 내역·어학·스킬을 포함한 모든 섹션은 `영역 삭제`로 지울 수 있습니다. `편집 버튼 표시`를 켜고 섹션에 마우스를 올린 뒤 삭제를 누르면, 확인 후 해당 영역과 내부 내용을 함께 삭제하고 자동 저장합니다. 직접 추가한 영역도 같은 방식으로 삭제할 수 있습니다.

별도의 Bullet 추가 버튼 없이 항목 본문을 클릭해 자유롭게 작성할 수 있습니다. Enter로 줄을 추가하고 Backspace로 지우며, 기존 Bullet 내용도 텍스트로 유지됩니다. 비어 있는 본문도 클릭해서 바로 입력할 수 있습니다. 작성 내용은 자동 저장되며, 빈 본문의 입력 안내는 PDF에 출력되지 않습니다.

수상 내역은 수상명 오른쪽에 수상일(YYYY.MM)을 표시하고 주최·수여 기관은 아래 줄에 유지합니다. 기존 저장 내용과 새로 추가하는 수상 항목에도 동일하게 적용됩니다.

- [기본형 열기](resume_template.html)
- [Compact형 열기](resume_template_compact.html)

`resume_template.html`에는 오픈소스 SVG 아이콘과 라이선스가 내장되어 있으므로 `icon/` 폴더 없이도 사용할 수 있습니다. `icon/` 폴더는 원본 SVG와 라이선스 확인을 위한 자료이며, 아이콘의 출처와 라이선스는 `icon/README.md`와 `icon/LICENSE`에서 확인할 수 있습니다.
